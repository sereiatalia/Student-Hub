# Student Hub

A student-focused web workspace for turning study materials into review tools.

## Current starter

- Upload UI for PDF and Word files
- Flashcards, live quiz, and reviewer export workspace tabs
- Demo notes flow for previewing the experience
- Device-local saved file state and theme preference
- Responsive layout for desktop and mobile

## Planned product flow

1. Upload and extract a PDF or DOCX.
2. Generate editable reviewer flashcards.
3. Practice with self-paced cards or a live quiz room.
4. Export a printable answer-sheet PDF.
5. Save study progress locally, with optional accounts later.

The current front end is intentionally framework-free HTML, CSS, and JavaScript so it can be opened and iterated quickly. Document parsing, AI generation, real-time rooms, and PDF rendering can be added as the backend layer matures.
